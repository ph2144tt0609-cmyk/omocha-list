# おもちゃひょう

子ども向けの「おうちのおもちゃ一覧」サイト。
ジャンル別に並び、**いま何分あそべるか**でしぼり込むと、その時間でできるおもちゃだけが出る。

- 公開URL: https://ph2144tt0609-cmyk.github.io/omocha-list/
- 実体は `index.html` 1ファイルのみ（ビルド不要・npm不要・オフラインでも動く）
- `<meta name="robots" content="noindex">` 付き（検索には出さない）

## つくり

| ところ | なかみ |
|---|---|
| `SEED` 配列（index.html 内） | おもちゃの正本データ。ここを直すと全員の画面が変わる |
| localStorage `omocha-list-v1` | サイト上で「ふやした／なおした」分。**その端末だけ**に保存される |

`min` = あそぶ時間のめやす（分）、`people` = `[さいしょう, さいだい]` 人数、
`age` = `[から, まで]` の対象年齢レベル。

| age | 意味 |
|---|---|
| 0 | ちいさい子（0〜3さい・未就園） |
| 1 | ようちえん・ほいくえん |
| 2 | 小学校 ていがくねん（1・2年） |
| 3 | 小学校 ちゅうがくねん（3・4年） |
| 4 | 小学校 こうがくねん（5・6年） |
| 5 | 大人 |

## つかいかた（子ども）

1. ⏰ どれくらいあそべる？ を選ぶ → その時間で終わるおもちゃだけになる
2. 👦 なんにんで／🗂 ジャンル でさらにしぼる
3. 🧩「じかんいっぱい あそぶ くみあわせ」→ その時間に収まる順番を提案
4. 🎯「ルーレットで きめる」→ まよったとき

## おもちゃを足すとき

- **みんなの画面に出したい**（本番に入れたい） → `index.html` の `SEED` に1行足して push
- ちょっと足すだけ → サイトの「➕ おもちゃを ふやす」（その端末だけ・書き出し／読み込みで移せる）

## 公開

```
git add -A && git commit -m "更新" && git push
```
main ブランチ直配信。push から1〜2分で反映。
